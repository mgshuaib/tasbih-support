# tasbih-support — صفحة الدعم والملاحظات لتطبيق «سبحة»

هذه الصفحة تُنشَر على GitHub Pages وتُلصق في خانة **Support URL** في App Store Connect.

## كيف تُنشر (مثل صفحة الخصوصية بالضبط)
1. أنشئ مستودعًا جديدًا على GitHub باسم `tasbih-support` واجعله **Public**.
2. ارفع إليه `index.html` (زر Add file ← Upload files).
3. Settings ← Pages ← Source: `Deploy from a branch` · Branch: `main` · Folder: `/ (root)` ← Save.
4. بعد دقيقة يصبح الرابط: **https://mgshuaib.github.io/tasbih-support/**
5. الصق هذا الرابط في: App Store Connect ← معلومات التطبيق ← **Support URL**
   (وضع نفس الرابط في التطبيق موجود أصلًا في `AppLinks.support`).
